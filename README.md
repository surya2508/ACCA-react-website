# ACCA Landing Page

A responsive ACCA education landing page built using React.js.

## Features

- Responsive design for desktop, tablet, and mobile
- Professional ACCA education landing page
- Header with navigation
- Become ACCA in 18 Months section
- Why Choose Us section
- ACCA Eligibility section
- What Will You Learn in ACCA section
- 100% Placement Assistance section
- Request Callback modal
- Responsive mobile design

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3

## Functionality

The **Request Call Back** button opens a success modal using React `useState`.

The modal displays:

> Request Submitted Successfully!

No backend or API is required.
